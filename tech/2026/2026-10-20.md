The team is reviewing the repositories and adjusting milestones for issues and pull requests.

The goal of 3.1-rc2 is to publish a version of the accompanying artifacts (OWL ontology, JSON schema, etc.) so that tools and libraries can begin using the updated artifacts and identifying issues.

The major change is the transition from IRIs with three-level version numbers to two-level version numbers (major.minor only).

Wording-only changes should not block the freeze and release of 3.1-rc2. These changes can safely be deferred for integration into 3.1-rc3.
